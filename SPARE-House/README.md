# SPARE House

## Project Overview
SPARE House is an e-commerce platform dedicated to providing high-quality spare parts for various Indian vehicles. The website is designed to offer a seamless shopping experience, allowing users to browse products, manage their accounts, and access support easily.

## Features
- User-friendly interface with responsive design.
- Comprehensive product catalog with filtering options.
- Secure user authentication and account management.
- Informative pages about the project and contact information.

## Installation
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd SPARE-House
   ```
3. Install dependencies:
   ```
   npm install
   ```

## Usage
- Open `src/pages/index.html` in your web browser to view the main landing page.
- Use the navigation menu to explore different sections of the website.
